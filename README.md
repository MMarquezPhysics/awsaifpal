# AWS AIF Pal for Streamlit

This folder is a self-contained Streamlit version of the local AWS AIF-C01 practice app. It includes all 512 questions, exam and guide modes, random question and option order, a timed session, scoring out of 1000, corrections, and saved attempt history with a configurable performance chart.

See [instructions.md](instructions.md) for local run and Community Cloud deployment steps.
